## 2. Методика [написано] 

Замысел - доказательство вспомогательных теорем для утверждения из статьи. 
Агент сначала планирует доказательство, потом ищет теоремы в Mathlib, затем по порядку доказывает теорема.
Правило принятия - доказательства проходят проверку и не содержат sorry.

Утверждение из статьи:
\begin{lemma}
The solution to the minimization problem
\[
\min_{L, R} \|g g^\top - L \otimes R\|_F
\]
equals to \(L = \sigma_1(G) u_1 u_1^\top\) and \(R = \sigma_1(G) v_1 v_1^\top\), where \(u_1\) and \(v_1\) are the left and the right singular vectors of \(G\) corresponding to the largest singular value \(\sigma_1(G)\). $g$ is the matrix $G$ reshaped into a vector.
\end{lemma}

Доказанные вспомогательные утверждения приведены ниже в разделе 3.

## 3. Верификатор [написано]

- **Что проверяет:** формулировки теорем приведены ниже.
- **Как устроен:** проверка доказательств с помощью движка lean.
- **Чего не проверяет:** -

Для доказательства утверждения статьи нужно SVD, а в Mathlib не оказалось теории SVD.
Поэтому агент доказал несколько вспомогательных теорем для матрицы Gᵀ G, подводящих к понятию SVD. Для доказательств использовался Mathlib.

**Формулировки теорем:**
GtG_symmetric: Gᵀ G симметричная.
GtG_IsHermitian: Gᵀ G эрмитова.
GtG_eigenvalues_nonneg: Собственные значения Gᵀ G неотрицательные.
frobenius_norm_sq_def: квадрат фробениусовой нормы равен суме квадратов элементов.
GtG_posSemidef: Gᵀ G неотрицательно определенная.

```lean
theorem GtG_symmetric (G : Matrix m n ℝ) :
  (G.transpose * G).transpose = G.transpose * G := by

theorem GtG_IsHermitian (G : Matrix m n ℝ) : (G.transpose * G).IsHermitian := by

theorem GtG_eigenvalues_nonneg (G : Matrix m n ℝ) :
  ∀ i, 0 ≤ (GtG_IsHermitian G).eigenvalues i := by

theorem frobenius_norm_sq_def (G : Matrix m n ℝ) :
  (∑ i, ∑ j, (G i j) ^ 2) = ‖G‖ ^ 2 := by

theorem GtG_posSemidef (G : Matrix m n ℝ) :
  ∀ x : n → ℝ, 0 ≤ ∑ i, x i * (∑ j, (G.transpose * G) i j * x j) := by
```
Все формулировки теорем и доказательства [порождены: моделью qwen3.6-35b-a3b/latest] агентом goose. Мною внесены только некоторые исправления.

## 8. Ограничения [написано]

Напишу здесь про опыт доказательств с агентов.
- агент не проверяет полностью свои доказательства, поэтому приходится за ним перепроверять и исправлять.
- у агента быстро засоряется контекст из-за поиска нужных теорем в Mathlib и запуска lean check.
- агент пишет некрасивые и очень длинные доказательства в координатах вместо использования более умных теорем. Потом эти доказательства перестают влезать в контекст.
- агент не следует инструкции записывать все необходимое в diary.md, из-за этого требуется повторный запуск. 

В папке ```agents_attempt``` содержатся файлы с теоремами, которые полностью написал goose агент без моих исправлений в попытке доказать утверждение из статьи. Во-первых, длинные доказательства на сотни строк в координатах выглядят удручающе. Во-вторых, в доказанных теоремах куча ошибок. В-третьих, осталось несколько sorry, которые агент не смог закрыть, потому что доказательства перестали влезать в разросшийся контекст.

Проверка правильности математических доказательств на lean с помощью агента остается очень сложной и трудоемкой задачей.
